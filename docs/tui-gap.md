# mini-dsh vs 官方 dsh-tui 差异对比

> 对比基准：官方 `@deepseek-ai/dsh-tui`（commit `10bb9cbf4a^`，2026-09-04 已删除）
> mini-dsh 版本：`infrastructure/tui/pi-tui/src/`（3 文件，~570 行）
> 官方版本：`packages/ui/tui/src/`（20+ 文件，~5000+ 行）

---

## 总览

| 维度 | 官方 dsh-tui | mini-dsh pi-tui | 差距 |
|---|---|---|---|
| 源文件数 | 20+ | 3 | 巨大 |
| 代码量 | ~5000+ 行 | ~570 行 | ~10x |
| 依赖 | pi-tui 0.80.7 + 10+ 组件 | pi-tui基础组件 | 大量 |
| 组件数 | 15+ | 4 | 巨大 |

---

## P0 — 关键体验缺失（阻断级）

### 1. Markdown 渲染

| 官方 | mini-dsh |
|---|---|
| 完整 Markdown 渲染：标题、代码块、粗体、斜体、链接、引用、列表 | 纯文本，无任何 Markdown 格式化 |
| 代码块有语法高亮（通过 pi-tui Markdown 组件） | 代码以纯文本显示 |
| 引用块有缩进 + 竖线装饰 | 无 |

**影响**：模型回复中的代码块、标题、列表全部以裸文本显示，可读性极差。

### 2. 斜杠命令系统

| 官方 | mini-dsh |
|---|---|
| `/help` — 显示快捷键和命令 | 无 |
| `/model [provider/]model` — 模型选择 | 无 |
| `/clear` — 清空转录视图 | 无 |
| `/details` — 工具卡片/推理显示设置 | 无 |
| `/status` — 会话诊断、system prompt、工具列表 | 无 |
| `/resume` — 列出可恢复会话 | 无 |
| `/exit` — 当前 turn 完成后退出 | `/exit`（立即退出） |
| `/skill:<name>` — 加载技能 | 无 |

**影响**：用户无法切换模型、查看状态、恢复历史会话。这些是日常使用最高频的操作。

### 3. 模型选择对话框

| 官方 | mini-dsh |
|---|---|
| 居中覆盖层，`╭ Select model ───╮` 边框 | 无 |
| 输入过滤（按 provider/model ID/描述） | 无 |
| Shift+Tab 切换推理强度 | 无 |
| 显示当前模型、provider、描述 | 状态栏仅显示 `?(?)` |
| 8 个可见选项，上下滚动 | 无 |

**影响**：启动后模型显示为 `?(?)`，无法切换模型。

### 4. 用户提问对话框（ask_user_question）

| 官方 | mini-dsh |
|---|---|
| 内联模态框，渲染在编辑器上方 | 无（`user-question` 事件已产生但无渲染） |
| 单选/多选/自定义答案三种模式 | 无 |
| Space 切换多选，Tab 切换自定义答案 | 无 |
| PageUp/PageDown 翻页长问题 | 无 |
| 终端过窄时紧凑渲染 | 无 |

**影响**：`ask_user_question` 工具已实现，但 TUI 完全不渲染问题卡片，用户看不到提问。

## P1 — 重要体验缺失

### 5. 状态栏信息

| 官方 | mini-dsh |
|---|---|
| 可配置模板：`${cwd}${git/worktree}${model}${token_meter/cache_hit_rate}${context}` | `mini-dsh  ?(?)  session-0001` |
| 显示当前工作目录（粗体 accent） | 无 |
| 显示 git 分支名（dim） | 无 |
| 显示 token 用量（↑输入 ↓输出） | 仅百分比 |
| 显示 KV cache 命中率 | 无 |
| 显示队列中的 steering 数量 | 无 |
| 左右分栏（左：信息，右：队列） | 单行 |

**影响**：用户无法知道当前目录、分支、token 消耗细节。

### 6. 步骤计时

| 官方 | mini-dsh |
|---|---|
| 每步显示计时：`Model wait 1.0s · Thinking 2.0s · Response 0.5s` | 无 |
| 四个阶段 TTFT/思考/响应/工具，各有独立 glyph | 无 |
| 增量累积器，O(events) 复杂度 | 无 |
| 时间戳落在 assistant 消息上 | 无 |

**影响**：用户无法感知模型响应速度，调试性能问题困难。

### 7. 工具卡片类型

| 官方 | mini-dsh |
|---|---|
| **Terminal 卡片**：`$ cmd` → `cwd` → 输出 → `[exit N]` | 通用卡片，纯文本 |
| **Diff 卡片**：`+ 新增行`(绿) `- 删除行`(红) 文件头 | 无 |
| **Generic/Read/Search/Web 卡片**：结构化 header + Markdown body | 无 |
| **未知工具**：XML 树渲染 | 无 |

**影响**：`bash` 输出、`write_file`/`edit_file` 的 diff 全部以纯文本显示，无法区分命令/输出/错误。

### 8. Todo/Plan 面板

| 官方 | mini-dsh |
|---|---|
| 编辑器上方渲染 `Plan` 标题 + 条目列表 | 无 |
| `✓`(绿) 已完成、`●`(黄) 进行中、`○`(dim) 待处理 | 无 |
| 每个 `turn/start` 清空 | 无 |

**影响**：`todo_write` 工具已实现，但任务列表在 TUI 中不可见。

### 9. 文件路径自动补全

| 官方 | mini-dsh |
|---|---|
| `@` 开头触发模糊文件搜索 | 无 |
| 目录作用域：`@path/` 列出子项 | 无 |
| 最大扫描 10000 条目，前缀/子串/子序列排序 | 无 |
| 排除 `.git`/`node_modules` | 无 |
| 与斜杠命令、会话引用合并 | 无 |

**影响**：用户必须手动输入完整文件路径。

### 10. 输入历史

| 官方 | mini-dsh |
|---|---|
| ↑/↓ 浏览历史命令 | 无 |
| 支持多行编辑（Shift+Enter/Alt+Enter） | 无 |

**影响**：无法重复之前的命令，长输入无法换行。

### 11. 状态 glyph 动画

| 官方 | mini-dsh |
|---|---|
| 提示符 `dsh >` 的 `>` 替换为阶段 glyph | `> ` 静态提示符 |
| 等待首 token: `◍`，推理: `✻`，生成: `●`，工具: `⚙`，压缩: `⊙` | 无 |
| 300ms 淡入、1400ms 周期脉冲、300ms 淡出 | 无 |
| 真彩色 24-bit 灰度渐变 | 无 |

**影响**：用户无法感知 agent 当前状态（等待中/推理中/生成中/执行工具中）。

## 优先级排序总结

| 优先级 | 数量 | 关键项 |
|---|---|---|
| **P0** | 4 | Markdown 渲染、斜杠命令（/model）、模型选择对话框、用户提问对话框 |
| **P1** | 7 | 状态栏（cwd/git/token）、步骤计时、工具卡片类型、Todo 面板、文件自动补全、输入历史、状态 glyph |
| **P2** | 6 | 颜色主题、Banner、会话恢复对话框、压缩指示器、上下文卡片、推理切换 |
| **P3** | 6 | 终端标题、折叠续文、Ctrl+L、会话引用、退出行为、多行输入 |

**建议实施顺序**：
1. P0-1: Markdown 渲染（pi-tui 内置 Markdown 组件，接入成本低）
2. P0-2: 斜杠命令 + P0-3: 模型选择对话框（联动）
3. P0-4: 用户提问对话框（ask_user_question 已有后端，差前端渲染）
4. P1-5: 状态栏（cwd/git 分支/token 详情）
5. P1-7: 工具卡片 Diff 类型（edit_file 需要）
6. P1-8: Todo 面板
